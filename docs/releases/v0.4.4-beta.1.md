# DevHarness Kit v0.4.4-beta.1 Release Notes

Status: beta developer preview. Do not describe this release as stable or 1.0-ready.

## Summary

`v0.4.4-beta.1` is a governance and release-hardening release. It does not expand
the Graph Lite parser surface. It closes the remaining Graph-aware Goal release
risks around stale graph overrides and graph snapshot retention audits.

## Stability

- Goal Orchestration: Beta developer preview.
- DB readonly: Beta; use database-level read-only credentials.
- Graph Lite: Alpha+; heuristic advisory impact analysis.
- Graph-aware Goal: Beta preview; freshness and impact evidence are enforced by
  goal checks, but graph output is still not a correctness proof.
- SQLite schema: v9, not a stable public API before 1.0.

## Highlights

- `dhk graph impact --allow-stale` now requires explicit approval evidence by
  default through `--allow-stale-evidence`.
- `.agents/devharness/policy.json` supports
  `graph_allow_stale_requires_approval`, defaulting to `true`.
- Graph-aware skill wrappers block weak-model self-service stale overrides
  unless `DHK_ALLOW_STALE_APPROVED=true` is set outside the agent flow.
- `dhk graph prune --dry-run` reports snapshots/files/nodes/edges/query-cache
  rows/goal bindings that would be deleted without modifying SQLite.
- Release archive names and wrapper fallback jar names now match
  `0.4.4-beta.1`.

## Verification

Before publishing this tag, run:

```bash
mvn -q test
mvn -q -DskipTests package
git diff --check
```

Also smoke-test the packaged jar:

```bash
java -jar target/dhk-cli-0.4.4-beta.1-all.jar version
java -jar target/dhk-cli-0.4.4-beta.1-all.jar graph init --project-root <tmp>
java -jar target/dhk-cli-0.4.4-beta.1-all.jar graph index --project-root <tmp>
java -jar target/dhk-cli-0.4.4-beta.1-all.jar graph impact --project-root <tmp> --file <file>
java -jar target/dhk-cli-0.4.4-beta.1-all.jar graph prune --project-root <tmp> --keep 10 --dry-run
```

## Known Limits

- Graph Lite is not a full AST or compiler-level call graph.
- `--allow-stale` is an emergency/manual escape hatch; re-indexing is preferred.
- Downgrade migrations are unsupported.
- Signed artifacts are not yet implemented.
