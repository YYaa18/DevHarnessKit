# DevHarness Kit v1.0.0 Stable Release

Status: stable. This is the first non-prerelease DevHarness Kit release.

## Summary

`v1.0.0` promotes the narrow DevHarness Kit core to a stable contract while
keeping experimental surfaces bundled for dogfooding and adapter compatibility.
The release remains local-first: no daemon, no cloud sync, and no LLM API calls.

## Stable Surface

The 1.0 stable contract covers:

- `dhk help` and `dhk version`
- `dhk doctor`
- `dhk configure init/show/doctor/explain`
- `dhk status` and `dhk readiness`
- `dhk advise` and `dhk quickstart`
- memory core: `init`, `add`, `confirm`, `search`, `export`, `checkpoint`,
  `recover`, and `backup`
- goal core: `start`, `resume`, `next`, `step`, `status`, `export`, `verify`,
  `complete`, `audit`, and `recheck`
- documented generated-export anchors for current context, goal context,
  goal summary, work brief, and artifact passport
- release packaging, checksums, license/security/changelog notices, and
  installer entrypoints

See `docs/STABLE_CONTRACT.md` and `docs/STABLE_CANDIDATE.md` for the exact
contract.

## Still Outside The Stable Contract

- DB inspection remains beta. Use appropriate local credentials; SQL guardrails
  and JDBC read-only hints are not a database permission boundary.
- Graph Lite and Graph-aware Goal remain experimental advisory context.
- BDD acceptance harness, skill governance, policy hooks, routine/metrics, and
  direct SQLite table details remain experimental or internal.
- `AGENT_BRIEF.json` remains alpha adapter protocol.

## Packaging Notes

Release artifacts are built from Maven `project.version`:

```text
dhk-cli-1.0.0-all.jar
devharnesskit-1.0.0.zip
devharnesskit-1.0.0.tar.gz
SHA256SUMS
```

The downloadable archives intentionally include only user-facing runtime
content: `lib/dhk.jar`, `install.sh`, README files, license/security/changelog
notices, agent skills, knowledge packs, Comate rules, and runtime setup scripts.
Repository docs, CI gates, release-process scripts, and development helper files
are not bundled.

## Notable Changes Since v0.4.6-beta.1

- README, security policy, release checklist, compatibility docs, and metadata
  checks now distinguish stable releases from prerelease beta wording.
- Release gates accept stable status markers for non-prerelease versions while
  retaining prerelease warning checks for versions with a hyphen suffix.
- The installer wizard has a clearer interactive flow and no longer looks for a
  fixed `0.4.6-beta.1` jar fallback.
- The 1.0 release keeps one shaded CLI jar and one release archive for install
  simplicity.

## Verification

Recommended release verification:

```bash
git diff --check
scripts/check-version-metadata.sh 1.0.0
mvn -B clean package -P release-archive
scripts/release-gate.sh --skip-package
java -jar target/dhk-cli-1.0.0-all.jar version
```

GitHub release assets should include the jar, zip, tarball, and SHA256 checksum
file generated from the final tagged commit.
