# DevHarness Kit v1.1.0 Stable Release

Status: stable. This release preserves the 1.0 stable core and adds
retrospective reporting plus stronger agent skill package coverage.

## Summary

`v1.1.0` is a compatibility-focused stable release. It keeps the documented
core stable surface intact while making completed goal work easier to review,
share, and attach to release or MR/PR evidence.

## New Features

- `dhk goal retrospective --goal <goal>` renders a human-readable Goal review
  summary.
- `dhk goal review-summary` and `dhk goal mr-summary` are compatibility aliases
  for the same report.
- `--json` produces the additive `goal-retrospective/v1-alpha` report schema.
- `--write <path>` writes a shareable Markdown report to disk.
- `dhk goal start --external-ref <ref>` and `--card-ref <ref>` attach an
  external issue, release card, PR, or review reference to the Goal.

## Reporting And Evidence Improvements

- `GOAL_CONTEXT.md`, `GOAL_SUMMARY.md`, and `ARTIFACT_PASSPORT.json` now surface
  Goal external references and timeline fields.
- Artifact passport evidence parsing now tolerates embedded `--field key=value`
  fragments so agent-formatting mistakes are less likely to hide valid manual
  evidence.
- Schema v16 adds `goal_run.external_ref` with a non-null default.

## Agent Skill Package Improvements

- The built-in `devharness-goal-development` skill now explicitly describes
  retrospective, review-summary, MR/PR summary, and Chinese "复盘材料" requests.
- The skill contract now declares the full Goal command surface it may use.
- Unix and Windows wrappers now cover all Goal subcommands exposed to the skill,
  including `audit`, `recheck`, `evidence-template`, `review-summary`, and
  `mr-summary`.
- Packaging tests now compare Goal command coverage against wrappers and skill
  contract declarations to prevent future drift.

## Stability Boundary

The 1.0 stable core remains compatible. Goal retrospective reporting and
skill-governance surfaces are stable-candidate unless explicitly promoted in a
future stable contract update. Direct SQLite table access and internal
`.agents/skills/` layout details remain outside the stable public API.

## Packaging Notes

Release artifacts are built from Maven `project.version`:

```text
dhk-cli-1.1.0-all.jar
devharnesskit-1.1.0.zip
devharnesskit-1.1.0.tar.gz
SHA256SUMS
ARTIFACT_MANIFEST.json
```

## Verification

Recommended release verification:

```bash
git diff --check
scripts/check-version-metadata.sh 1.1.0
mvn -B clean package -P release-archive
scripts/release-gate.sh --skip-package
java -jar target/dhk-cli-1.1.0-all.jar version
```

GitHub release assets should include the jar, zip, tarball, SHA256 checksum
file, and `ARTIFACT_MANIFEST.json` generated from the final tagged commit.
