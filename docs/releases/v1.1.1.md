# DevHarness Kit v1.1.1 Stable Patch Release

Status: stable. This patch release rebuilds the installable package from the
latest main branch after `v1.1.0`.

## Summary

`v1.1.1` keeps the v1.1 stable surface compatible and focuses on packaging the
latest onboarding and agent-safety improvements for users installing from GitHub
Releases.

## Changes Since v1.1.0

- Added focused `EvidenceValueParser` unit tests for plain fields, embedded
  `--field key=value` evidence, quoted and escaped values, duplicate keys, and
  empty input.
- Improved installer guidance and the Chinese business-development acceptance
  plan used for colleague onboarding.
- Hardened Work Brief / Agent Brief pre-work confirmation behavior so agents
  keep waiting for explicit user confirmation before business-file writes.
- Added `pre-work-file-write` verification coverage to catch business-file
  changes that happen before the confirmation baseline.
- Kept the release package to the single integrated
  `devharness-goal-development` skill; the obsolete graph-aware helper skill is
  not packaged separately.

## Stability Boundary

The v1.1 stable surface remains compatible. DB inspection remains beta, and SQL
guardrails are still not a database permission boundary.

## Packaging Notes

Release artifacts are built from Maven `project.version`:

```text
dhk-cli-1.1.1-all.jar
devharnesskit-1.1.1.zip
devharnesskit-1.1.1.tar.gz
SHA256SUMS
ARTIFACT_MANIFEST.json
```

## Verification

Recommended release verification:

```bash
git diff --check
scripts/check-version-metadata.sh 1.1.1
mvn -B clean package -P release-archive
scripts/release-gate.sh --skip-package
java -jar target/dhk-cli-1.1.1-all.jar version
```

GitHub release assets should include the jar, zip, tarball, SHA256 checksum
file, and `ARTIFACT_MANIFEST.json` generated from the final tagged commit.
