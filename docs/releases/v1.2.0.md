# DevHarness Kit v1.2.0 Stable Release

Status: stable. This release keeps the 1.0 stable core compatible and adds a
memory quality layer for safer CLI and agent workflows.

状态：stable。本版本保持 1.0 稳定核心兼容，并新增一层 memory 质量治理能力，
让 CLI 和 Agent 使用记忆时更安全、更可审计。

## Summary / 概览

English:

`v1.2.0` improves project memory from “store and search confirmed facts” toward
“generate, review, govern, rank, and share reusable context”. New workflows are
CLI-first, local-first, and keep human confirmation in the loop.

中文：

`v1.2.0` 将项目记忆从“保存并检索已确认事实”推进到“生成、审核、治理、排序和
共享可复用上下文”。新增流程仍然是 CLI 优先、本地优先，并保留人工确认。

## Changes Since v1.1.1 / 相比 v1.1.1 的变化

English:

- Added `dhk memory suggest` and `dhk memory candidates list|accept|reject`.
  Accepted candidates become draft memory and still require `memory confirm`.
- Added `dhk memory dedupe`, `memory conflicts`, and `memory supersede` for
  duplicate, contradiction, and replacement governance.
- Added `dhk memory stale scan`, `memory expire`, and `memory refresh` for stale
  memory lifecycle management.
- Added richer `memory search --explain` score details, including positive
  ranking components and stale/superseded penalties.
- Added `dhk memory pack create|inspect|import` with checksum validation, unsafe
  zip entry rejection, and default draft imports for team onboarding.
- Added schema v17 for memory candidate and lifecycle metadata.
- Added integration coverage for candidate review, sensitive data rejection,
  duplicate acceptance, stale refresh, ranking penalties, team pack import, and
  unsafe zip entries.

中文：

- 新增 `dhk memory suggest` 和 `dhk memory candidates list|accept|reject`。
  接受候选只生成 draft memory，仍需要 `memory confirm` 才能进入默认上下文。
- 新增 `dhk memory dedupe`、`memory conflicts`、`memory supersede`，用于重复、
  冲突和替代关系治理。
- 新增 `dhk memory stale scan`、`memory expire`、`memory refresh`，用于过期记忆
  生命周期管理。
- 增强 `memory search --explain`，展示排序加分项和 stale/superseded 降权。
- 新增 `dhk memory pack create|inspect|import`，支持 checksum 校验、危险 zip
  entry 拒绝和团队导入默认 draft。
- 新增 schema v17，用于记忆候选和生命周期元数据。
- 新增集成测试覆盖候选审核、敏感数据拒绝、重复接受候选、过期刷新、排序降权、
  团队 pack 导入和危险 zip entry。

## Stability Boundary / 稳定性边界

English:

Existing stable memory commands remain compatible. New memory quality commands
are stable-candidate CLI surfaces in this release. SQLite schema/table/column
details remain internal; consume the CLI and generated exports instead.

中文：

已有 stable memory 命令保持兼容。本版本新增的 memory quality 命令属于
stable-candidate CLI surface。SQLite schema/table/column 仍是内部实现，请通过
CLI 和生成导出文件消费。
