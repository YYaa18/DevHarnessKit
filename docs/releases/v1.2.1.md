# DevHarness Kit v1.2.1 Stable Patch Release

Status: stable patch. This release publishes a fresh installable package from
the latest main branch after `v1.2.0`.

状态：stable patch。本版本基于 `v1.2.0` 之后的最新 main 分支重新发布可安装包。

## Summary / 概览

English:

`v1.2.1` keeps the 1.2 stable memory quality surface and packages the latest
correctness fixes for memory governance, BDD acceptance, Graph Lite advisory
precision, and pre-work agent interaction.

中文：

`v1.2.1` 保持 1.2 稳定 memory 质量治理能力不变，并打包最新的 memory 治理、BDD
验收、Graph Lite advisory 精准性和 Agent 写文件前确认修复。

## Changes Since v1.2.0 / 相比 v1.2.0 的变化

English:

- Fixed `memory refresh` so refreshed expired/deprecated memory can become
  active again when new evidence verifies it.
- Improved `memory conflicts` by surfacing same-key fact variants with
  different fingerprints, covering numeric and factual drift that is not
  expressible through a small antonym dictionary.
- Added focused integration coverage for stale, expire, and refresh lifecycle
  behavior.
- Included BDD, Graph Lite, and interaction correctness hardening already
  merged to main.
- Kept SQLite schema at v17; this release does not introduce a migration.

中文：

- 修复 `memory refresh`：已过期或 deprecated 的记忆在补充新证据后可以重新变为
  有效状态。
- 增强 `memory conflicts`：同一 key 下 fingerprint 不同的事实版本会被提示，
  覆盖数字、事实类描述漂移，不再只依赖少量反义词字典。
- 增加 stale、expire、refresh 生命周期的定向集成测试。
- 纳入已合入 main 的 BDD、Graph Lite 和交互确认正确性加固。
- SQLite schema 保持 v17，本次发布不包含数据库迁移。

## Stability Boundary / 稳定性边界

English:

The documented 1.2 stable surface remains compatible. Memory quality commands
stay CLI-first and local-first. SQLite schema/table/column details remain
internal; consume the CLI and generated exports instead.

中文：

文档化的 1.2 stable surface 保持兼容。memory 质量治理命令仍然是 CLI 优先、本地
优先。SQLite schema/table/column 仍是内部实现，请通过 CLI 和生成导出文件消费。
