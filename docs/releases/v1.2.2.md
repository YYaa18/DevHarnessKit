# DevHarness Kit v1.2.2 Stable Patch Release

Status: stable patch. This release publishes a fresh installable package that
includes the goal-agent hardening commit after `v1.2.1`.

状态：stable patch。本版本基于 `v1.2.1` 之后的 goal-agent 加固提交重新发布
可安装包。

## Summary / 概览

English:

`v1.2.2` keeps the 1.2 stable surface compatible and strengthens the bundled
goal agent for restricted or legacy projects where local builds may be
unavailable. It improves how agents reuse prior troubleshooting knowledge and
how they stop build/test retry loops.

中文：

`v1.2.2` 保持 1.2 稳定边界兼容，并强化内置目标 Agent 在受限或遗留项目中的
行为约束：更好地复用既有排障知识，也避免在无法本地编译时反复重跑构建/测试。

## Changes Since v1.2.1 / 相比 v1.2.1 的变化

English:

- Allowed `dhk memory search` and `dhk memory suggest` inside the goal skill
  contract for a safe error-to-solution loop.
- Kept `dhk memory confirm` and candidate acceptance forbidden for agents, so
  trusted reusable memory still requires user control.
- Added explicit guidance that agents must not retry failing or hanging
  build/test commands in a loop.
- Updated goal protocol and forbidden-action references with the same memory
  and verification boundaries.
- Updated `scripts/devharness-control-panel.sh` generated adapter guidance so
  installed Claude Code, OpenCode, and Comate rules carry the new constraints.
- Expanded `GoalSkillPackagingTest` to lock the new contract and generated
  rule content.
- Kept SQLite schema at v17; this release does not introduce a migration.

中文：

- 在 goal skill contract 中允许 `dhk memory search` 和 `dhk memory suggest`，
  用于安全的错误到解决方案闭环。
- 继续禁止 Agent 自行执行 `dhk memory confirm` 或接受候选，可信可复用记忆仍由用户
  控制。
- 明确要求 Agent 不要对失败或卡住的构建/测试命令进行循环重试。
- 同步更新 goal protocol 和 forbidden-action 说明，保持 memory 与验证边界一致。
- 更新 `scripts/devharness-control-panel.sh` 生成的适配器说明，让已安装的
  Claude Code、OpenCode 和 Comate 规则带上这些新约束。
- 扩展 `GoalSkillPackagingTest`，锁定新的 contract 和生成规则内容。
- SQLite schema 保持 v17，本次发布不包含数据库迁移。

## Stability Boundary / 稳定性边界

English:

The documented 1.2 stable surface remains compatible. This patch changes bundled
agent guidance and packaging tests, not the SQLite schema. Memory confirmation
and candidate acceptance remain user-controlled operations.

中文：

文档化的 1.2 stable surface 保持兼容。本补丁修改的是内置 Agent 指引和 packaging
测试，不改变 SQLite schema。memory 确认与候选接受仍然是用户控制动作。
