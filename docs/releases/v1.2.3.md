# DevHarness Kit v1.2.3 Stable Patch Release

Status: stable patch. This release publishes a fresh installable package with
the latest Graph Lite advisory precision and stale snapshot fixes.

状态：stable patch。本版本发布新的可安装包，包含最新的 Graph Lite advisory
精准性与 stale snapshot 修复。

## Summary / 概览

English:

`v1.2.3` keeps the 1.2 stable surface compatible and improves Graph Lite's
advisory impact behavior. Interface changes now surface same-package
implementations, and graph freshness checks detect touch-only file changes.

中文：

`v1.2.3` 保持 1.2 稳定边界兼容，并改进 Graph Lite 的 advisory impact 行为。
接口变更现在能召回同包实现类，graph freshness 检查也能检测仅更新时间戳的文件变更。

## Changes Since v1.2.2 / 相比 v1.2.2 的变化

English:

- Fixed Java Lite inheritance target resolution so same-package
  `implements`/`extends` edges point to the declared fully qualified type node.
- Added a graph-specific workspace fingerprint based on scanned file path,
  language, kind, size, content hash, skip metadata, and modified time.
- Updated `graph index`, `graph status`, `graph impact`, and graph-aware Goal
  checks to use the same `graph:` fingerprint contract.
- Kept inheritance impact precise by traversing from interface/base type to
  implementation/subclass while avoiding expansion from concrete classes back
  into shared base classes.
- Added regression coverage for interface-to-implementation impact and
  touch-only stale detection.
- Kept SQLite schema at v17; this release does not introduce a migration.

中文：

- 修复 Java Lite 继承目标解析：同包 `implements`/`extends` 边会指向已声明的
  全限定类型节点。
- 新增 Graph 专用 workspace fingerprint，基于扫描文件路径、语言、类型、大小、
  内容 hash、跳过元数据和修改时间生成。
- `graph index`、`graph status`、`graph impact` 和 graph-aware Goal 检查统一使用
  同一套 `graph:` fingerprint 契约。
- 保持继承影响的精准性：从接口/基类扩散到实现/子类，但避免从具体类回扩到共享基类。
- 增加接口到实现 impact 与 touch-only stale detection 回归测试。
- SQLite schema 保持 v17，本次发布不包含数据库迁移。

## Stability Boundary / 稳定性边界

English:

The documented 1.2 stable surface remains compatible. Graph Lite is still an
advisory/heuristic capability and must not be treated as a correctness proof.

中文：

文档化的 1.2 stable surface 保持兼容。Graph Lite 仍是 advisory/heuristic 能力，
不能当作正确性证明。
