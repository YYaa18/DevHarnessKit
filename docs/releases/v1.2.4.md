# DevHarness Kit v1.2.4 Stable Patch Release

Status: stable patch. This release publishes a fresh installable package with
the latest memory freshness ranking and stale-knowledge retirement fixes.

状态：stable patch。本版本发布新的可安装包，包含最新的 memory freshness
排序和旧知识自动退役修复。

## Summary / 概览

English:

`v1.2.4` keeps the 1.2 stable surface compatible and improves the memory quality
workflow. Confirming a newer version of the same project fact now retires older
confirmed versions, and memory search gives fresher evidence a small, explainable
ranking advantage.

中文：

`v1.2.4` 保持 1.2 稳定边界兼容，并改进 memory 质量治理流程。确认同一项目事实的
新版本时，旧 confirmed 版本会自动退役；memory search 也会给更新鲜的证据一个可解释
的小幅排序优势。

## Changes Since v1.2.3 / 相比 v1.2.3 的变化

English:

- Retired older confirmed memory entries when a newer same-topic entry with
  different content is confirmed.
- Reported auto-retired entries from `memory confirm` through
  `superseded_same_topic` and `superseded_ids`.
- Added freshness-aware memory search scoring:
  recently verified or updated memories receive `fresh:+2`, while memories
  untouched for 180 days or more receive `aging:-2`.
- Added regression coverage proving that newer same-topic memories outrank
  superseded older ones.
- Kept SQLite schema at v17; this release does not introduce a migration.

中文：

- 确认同主题且内容不同的新 memory 时，自动退役旧 confirmed memory。
- `memory confirm` 会通过 `superseded_same_topic` 和 `superseded_ids` 返回自动退役结果。
- 增加 freshness-aware memory 检索评分：近期验证或更新的记忆得到 `fresh:+2`，
  180 天及以上未维护的记忆得到 `aging:-2`。
- 增加回归测试，证明同主题新记忆会排在被替代的旧记忆之前。
- SQLite schema 保持 v17，本次发布不包含数据库迁移。

## Stability Boundary / 稳定性边界

English:

The documented 1.2 stable surface remains compatible. Memory search ranking is
explainable but still heuristic; users should confirm project facts before they
enter default context.

中文：

文档化的 1.2 stable surface 保持兼容。memory search 排序是可解释的启发式能力；
项目事实进入默认上下文前仍应由用户确认。
