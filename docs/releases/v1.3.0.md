# DevHarness Kit v1.3.0 Context Governor Release

Status: stable. This release promotes the Context Governor storage, budgeting,
rendering, and diagnostics surface into the documented stable release package.

状态：stable。本版本将 Context Governor 的存储、预算、渲染和诊断能力纳入正式发布包。

## Summary / 概览

English:

`v1.3.0` keeps the 1.0 stable core and 1.2 memory quality workflows compatible
while adding a practical context-management layer for long agent sessions. Large
build/test/shell evidence is compressed into local artifacts, generated context
is budgeted by token-oriented sections, and release validation now includes
64k, 128k, and 200k context-window acceptance tests.

中文：

`v1.3.0` 保持 1.0 稳定核心和 1.2 memory 质量治理能力兼容，同时增加面向长 Agent 会话的
上下文治理层。大型 build/test/shell 证据会压缩为本地 artifact，生成上下文会按近似
token 分区预算控制，发布验证也覆盖 64k、128k、200k 三档上下文窗口。

## Changes Since v1.2.4 / 相比 v1.2.4 的变化

English:

- Added schema v18 for `context_artifact` and the repository/service layer for
  compressed evidence storage.
- Added build, test, and shell output compressors that preserve root cause,
  exit code, retained spans, and artifact references.
- Added context commands: `stats`, `artifacts`, `retrieve`, `render`, and
  `doctor`.
- Added token-budget and truncation reports to generated context exports.
- Added graph context digest and memory budget integration so advisory/stale
  context remains visible without overwhelming the prompt.
- Added automated context-window acceptance tests for 64k, 128k, and 200k
  budgets.
- Kept Context Governor honest as a budgeting and evidence-recovery layer, not
  a correctness proof.

中文：

- 新增 schema v18 和 `context_artifact` 存储层，用于压缩证据的本地保存与恢复。
- 新增 build、test、shell 输出压缩器，保留 root cause、exit code、retained spans
  和 artifact reference。
- 新增 context 命令：`stats`、`artifacts`、`retrieve`、`render`、`doctor`。
- 在生成上下文中增加 token-budget report 和 truncation report。
- 接入 graph context digest 和 memory budget，让 advisory/stale 上下文可见但不淹没
  prompt。
- 新增 64k、128k、200k 三档上下文窗口自动化验收。
- Context Governor 定位保持诚实：它是预算编排和证据恢复层，不是正确性证明。

## Stability Boundary / 稳定性边界

English:

The stable contract covers the documented command names, JSON fields, generated
context anchors, release artifact shape, and schema migration behavior. Token
counts remain approximate (`ceil(chars/4)`), graph impact remains advisory, and
headroom compression remains an explicit experimental adapter.

中文：

稳定承诺覆盖文档化命令名、JSON 字段、生成上下文锚点、发布包形状和 schema 迁移行为。
token 计数仍是近似值（`ceil(chars/4)`），graph impact 仍是 advisory，headroom
compression 仍是显式 experimental adapter。

## Packaging Notes / 打包说明

Release artifacts are built from Maven `project.version`:

```text
dhk-cli-1.3.0-all.jar
devharnesskit-1.3.0.zip
devharnesskit-1.3.0.tar.gz
SHA256SUMS
ARTIFACT_MANIFEST.json
```

The user package intentionally excludes the repository `docs/` directory and
development-only release scripts. It includes `install.sh`, the runtime jar,
agent skills, knowledge packs, Comate rules, README files, security notes,
license, third-party notices, and changelog.

## Verification / 验证

Release verification used for this build:

```bash
git diff --check
scripts/check-version-metadata.sh 1.3.0
mvn -q -DskipTests compile
mvn -q test
mvn -B clean package -P release-archive
scripts/release-gate.sh --skip-package
java -jar target/dhk-cli-1.3.0-all.jar version
```
